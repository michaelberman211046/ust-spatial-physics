# Publication manifest

This snapshot contains the active pipeline modules and logging support package, including the coarse and fine Eikonal refinements used for the reported synthetic and measured reconstructions. It also contains three executable PowerShell configurations, one human-readable configuration summary, static verification tooling, dependency metadata, data/provenance documentation, citation metadata, and an MIT license.

Large generated artifacts are intentionally external. See `docs/DATA.md` and `docs/CHECKPOINTS.md`.
